## Compatibility and general architecture

The importer accepts validated v0.2 worlds, dry-run scenes and saved HTTP envelopes. It archives original input and supplied authoring source as inert resources. It translates each independent orbit and meter, preserves fixed versus live membership, and applies explicit day-to-second and nominal-unit conversions. It reports camera and marker changes, archived focus cues and old history, plus any limits on contact-guided curve sampling. Incompatible input fails with a field path. Five existing SDK recipes retained their conjunction-time results.
