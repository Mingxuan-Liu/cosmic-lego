# F06 — Planetarium application shell handoff

Implemented **2026-11-03** on F01–F05. The existing Three adapter now occupies
the full workspace, with movable inspector, plots, model/provenance and

## Authoring and compilation contracts

`src/workspace/index.js` exports `registerWorkspaceExtensions`,
`createWorkspaceLayer`, `workspaceExtensions`, `WORKSPACE_FORMAT`,
`PLOT_SOURCE_TYPE`, and `WORKSPACE_LIMITS`. The trusted composition root installs
four F03 view factories with `workspace.data`: `workspace.inspector`,
`workspace.plot`, `workspace.provenance`, and `workspace.conversation`.
Their output format is `cosmic.workspace.overlay.v1`.

`createWorkspaceLayer(binding)` exposes `validators`, `scene`, `author(draft)`,
`sources(project)` and async `compile(project,{results,time,capabilities})`.
The result is `{valid,identity,time,scene,overlays,diagnostics}`; `scene` is the
ordinary F05 snapshot. Supply current F04 results at one physical sample time.
Missing/stale/incompatible values never cause fallback scientific evaluation.
Inputs are detached before awaiting, and identity is checked before publication.

Author methods are `create(kind,options)`, `inspector`, `plot`, `provenance`,
`conversation`, `bind(plot,source,{port,component})`, `update`, `duplicate`, and
`remove`. They return F01 draft handles. Accept through the workspace validators.
Layouts are flat parameters: `title,x,y,width,height,folded,hidden`; plots also
carry `component` (−1 for all vector components, or 0–2). All view instances can
be independently created, bound, arranged, duplicated and removed. The fixture
inventory is ordinary author code, not a shell enumeration.

The four F03 factories produce layout data. Each plot additionally owns exactly
one F01 `workspace.plot-source` relationship with source/target references,
dependencies and `{port,contract}` data. Its contract is the actual inferred F02
descriptor. Workspace validation rejects missing/duplicate links, unavailable
ports, altered unit/frame/meaning/normalization contracts and unsupported shapes.
Rebind explicitly when a source contract changes. Duplicating a plot copies its
edge and shares the science source; removing it removes its owned edge first.
This uses existing F01 authority rather than expanding F03's deliberately small
schema language to express arbitrary nullable scientific port templates.

Compiled plots add full F02 `data`, `source:{nodeId,port,implementation,identity}`,
`sampling`, and `sampleMode:'current-physical-time'`. `validateSuppliedResult`
was factored into `src/registry/results.js` and exported from the registry so
F03/F05 and F06 share Value, producer, identity, descriptor and time validation.
The scene layer accepts a trusted host option `additionalViewFormats`;
the workspace declares only its own overlay format. Other unknown view formats
still fail explicitly rather than being silently ignored.

Defaults bound the workspace to 16 overlays and 10,000 scientific entries per
plot. Layout coordinates/dimensions are finite bounded data; dimensions can be
as small as 1 when the viewport demands it, while the window manager applies
useful display minima. Existing scene, graph, result and runtime budgets remain.
No equations, provider code, source evaluation, network assets or new renderer
were introduced.

## Selection, plots and scientific time

The application exposes stable selection through `cosmicWorkspace.state` and
`cosmic:selection` events. Selection records carry `nodeId` and optionally
`port`, `objectId` and `instanceIndex`. Scene selections are checked by the F05
adapter; scientific sample selections are checked against current Value IDs or
field sample indices. Unknown IDs reject. Vanished selections clear on refresh.
No label text or screenshot location is used as application identity.

The inspector, plots, conversation context and renderer use one accepted
identity and physical time. Plots display actual current scalar/vector,
collection or field values. Collection/field horizontal axes are explicitly
sample indices, with persistent source IDs retained. They are not invented
time histories or spatial distances. Vector plots can show one component or all
three. Null samples are omitted with a count; a range too large for finite SVG
coordinates yields a visible diagnostic instead of NaN geometry. Clicking a
sample selects its matching scene instance when one exists, otherwise its
scientific source/sample. The inspector supports actual producer port names.

The fixture uses the F05 moving collection and fields. Its derived plot is
`reduce('mean', map('magnitude', moving-collection))`: **mean position magnitude**,
not a vector centroid. At 2 s its value is **2.8817425997262003 m**. A second
independent field plot is created and removed through the same public operations.
Camera, window and presentation edits preserve scientific Values at fixed time.
F04 still owns computation; requestAnimationFrame only draws the last scene.

## Overlay layout, recovery and focus

`src/workspace/browser.js` exports `clampLayout` and `createOverlayManager`.
The manager consumes keyed flat overlay records and accepts callbacks for
accepted changes, focus, removal and errors. Its public methods are `render`,
`setSceneOnly`, `focus`, `body`, `resize`, and `dispose`. Bodies remain stable
across layout changes. Content is supplied by the application; the manager has
no domain, scientific evaluator, provider or project imports.

Drag a window title or its resize corner using mouse, pen or touch. Pointer
capture keeps gestures coherent; cancellation rolls back the preview. The
manager clamps every visible title/control inside the available viewport, even
after resizing. Only completed gestures submit changes; pending changes remain
visible until acknowledgement and roll back on rejection. Authored geometry is
clamped for display on a narrow viewport without silently rewriting the project
on every browser resize. Narrow views overlap; the Views menu raises/restores a
chosen view, and Fold all or Scene only exposes the stage.

Titles are keyboard focus targets: arrows move 10 px, Shift+arrows resize,
Alt reduces the step to 1 px. Resize handles also support arrows. Escape from a
panel returns focus to the overlay container; IME composition is respected.
Folded content is hidden/inert; hidden windows neither intercept pointers nor
remain in keyboard navigation. Hide/restore retains the mounted body and draft;
focus recovery prefers the previously focused content when applicable. Metadata
expansion and content scroll positions survive ordinary scientific refreshes.

**V** toggles Scene only; **Escape** restores it; **F** fits the scene. These
shortcuts do not consume ordinary typing in inputs. A visible Restore workspace
button always remains in scene-only mode. Views lists hidden windows and offers
new bound plots. Undo/Redo uses F01 history for accepted layout and view edits.
Camera navigation, stacking/focus, menu state and Scene only are transient UI
state. Reduced-motion preference removes navigation damping and CSS motion;
playback remains explicitly user-controlled.

## Conversation event boundary

`src/workspace/session.js` exports `createConversation({onEvent})`, with
`snapshot`, `subscribe`, `context`, `draft`, `forgetDraft`, `submit`, `cancel`,
and `receive`. Every composer uses this model; its layout does not depend on a
provider. The default is honestly disconnected, Send disabled, with editable
drafts. There are no canned assistant replies or credentials.

The host injects a `connection` event with disconnected/connecting/connected/error
status. For a connected explicit submit, the model emits
`{type:'submit',turnId,composerId,text,context}` containing a detached selection,
project identity and sample time. Incoming `message`/`delta`, `progress`, `error`
and `complete` events must name the current turn. Stop emits `cancel`, clears
local progress, and rejects late chunks. Transport callback failures are visible
and preserve an unsent draft; failed cancellation callbacks cannot un-revoke the
local turn. Normal revisions retain a live turn, while a new project/load
generation cancels it and clears context-specific drafts/messages.

Drafts survive hiding/folding/scene-only changes in this page. Removing a
composer explicitly forgets its draft to bound memory; Undo restores the view
definition, not deleted draft text. Drafts/transcripts are not persisted across
page reloads in F06. Limits are 24 drafts, 200 messages/remembered turns, 12,000
characters per draft/message and bounded progress/error labels.

The app emits host-facing `cosmic:conversation` CustomEvents. F08 may inject
transport events through `cosmicWorkspace.conversation`; public tests label all
injected messages **TEST ONLY**. Those tests are evidence of the UI boundary,
not a connected agent. F08 must supply real session/authentication handling and
bind cancellation to actual jobs and gateway write revocation. This model alone
cannot revoke an external process's filesystem or tools.

## Local host and public browser operations

Run `bash scripts/node.sh scripts/scene-server.mjs --workspace --port 4326`
and open `http://127.0.0.1:4326`. Plain `node` also works when installed on PATH.
The F05 default server mode and port remain supported. Dependencies remain the
same pinned Three.js package; the approved logo bytes and BSD/MIT notices remain.

Workspace mode serves `/api/workspace/state`, `/evaluate`, and `/edit`. State
includes graph, identity, history, discovery, required sources and actual output
descriptors. Evaluation returns F04 results plus the workspace snapshot. Edit
actions include overlay create/bind/duplicate/update/remove, Undo/Redo and the
earlier narrow demo scene controls. Create-plus-bind is one accepted transaction.
Requests retain full identity checks, byte bounds, loopback Host/Origin checks
and static resource allowlists. This is the demo host, not the F07 gateway.

`cosmicWorkspace.views` exposes `create`, `bind`, `duplicate`, `update`, and
`remove`. Its operations queue against the latest accepted token. The same
object exposes `select`, `refresh`, `edit`, `setSceneOnly`, `adapter`,
`conversation`, and detached selection state/current snapshots for integration
and inspection. These browser helpers do not replace the public F01 author
handles or grant an unvalidated write route.
